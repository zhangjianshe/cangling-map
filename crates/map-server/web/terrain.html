垂直基准该如何填写？

填写 DEM 像元高程值所参照的高程参考面，以数据提供方说明为准。例如 EGM96（EPSG:5773）、1985 国家高程基准，或 WGS84 椭球高。EPSG:4326 只描述水平位置，不能据此判断高程基准。来源不明时填写“未知（待核实）”，不要猜测。填写此字段不会触发高程基准转换；同一数据集的源文件应使用相同基准。
